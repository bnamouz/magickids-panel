# סוכני הקול כקוד

התיקייה שומרת את ההגדרות של שרה (מענה המכון) ונור (מזכירה אישית), כך שכל שינוי בהנחיות עובר דרך GitHub כמו כל שינוי אחר בפאנל.

| קובץ | תוכן |
|---|---|
| `prompt.md` | ההנחיות המלאות של הסוכנת |
| `first-message.txt` | משפט הפתיחה |
| `agent.json` | שפה, מודל, כלים ו־webhook לצורך בקרה. הטוקן מוסתר (`${VOICE_AGENT_TOKEN}`) |

## תהליך שינוי

1. עורכים את `prompt.md` או `first-message.txt` בענף ופותחים PR.
2. אחרי המיזוג: `npm run agents:push`. הסקריפט מעדכן רק את מה שהשתנה ובודק שהשינוי נקלט ב־ElevenLabs.
3. `npm run agents:check` משווה את המאגר מול ההגדרות החיות ומדווח על כל שינוי שנעשה ידנית ב־ElevenLabs. במקרה כזה מריצים `npm run agents:pull` ושומרים את השינוי ב־PR.

כלים, מספרי טלפון ו־webhooks אינם נדחפים אוטומטית; הם נשמרים כאן כדי לזהות שינוי.
